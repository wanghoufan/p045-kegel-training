## 勘误裁量与明确假设

1. 耐力 5/6/8/8/10/10 是 V1.4 **每次完整组合/耐力专项会话**的次数，不是日次数；保持/放松完全恢复原矩阵，不放大耐力组。
2. 快速 10/20/30/50/80/120 是**每日满量目标**；L6 120＝全天 6 个 20 次组。每快速组最多20，末组可为余数；日绝对快速上限240，仅是产品计数上限，L6默认不是240。
3. 「120次、6组完成一次满量」不能解释为一次启动120：这与单会话两类合计≤40矛盾。因此本版将满量定义为一天的目标；保留≤40，按会话拆快速组。跨会话不能拼接正在执行的组，也不能跳过30秒组间休息；每日实际组数可能比 ceil(日快速/20) 多。
4. L1 快速放松取4秒（初学者比例）；L2–L6 均2秒。快速梯次没有直接临床依据，是用户允许采用的可调产品默认；后续调参仍需受控变更，不在当前版本自由输入240。
5. 按上述口径，L6 每次约4.93分钟、每日29.60分钟；不是每次13–15/每日60–90分钟。后者与现有次数、秒数、休息不符，不为凑时长增加收缩或休息。V2.0 的55:36也是**每日**值，不是单次值。

## 产品目标与继承范围

- Product Goal：交付 Android 优先的 V1 训练辅助与自我记录工具。成年男性可完成自报能力摸底，在安全门槛满足时取得产品训练等级 L1–L6，从「今日训练」或专项入口跟随语音完成耐力与快速控制训练，也可在公共场合选择无声跟练、查看分项历史并主动重新摸底；另有默认关闭的可选 EHS 自评与个人趋势，仅供参考且不参与训练等级。成功判据是核心流程、异常退出和休息降量路径均可验收；不得宣称诊断或治疗效果。
- Target Users：希望进行男性盆底肌专项训练、不使用器械且训练时不愿持续盯屏的成年男性；常在居家、工作间隙坐着或站着训练，可能戴耳机、锁屏或把手机放在口袋。对动作识别、放松质量或症状有疑虑的人需要明确的暂停与求助出口。
- Problem：初学者不清楚正确动作和起始难度；普通倒计时缺少耐力与快速控制的分轨引导；盯屏增加训练负担；训练记录与分级容易被误解成临床肌力评估。现有竞品和用户访谈证据尚不足以判断这些问题的普遍程度，Research Reviewer 应核验。

上述非医疗定位、人群与问题沿用 V2.0（其历史来源为 V1.4）。Core Value：可选摸底或自选等级→语音/低调跟练→双维记录→主动重测与质量反馈，放松与收紧同等重要；升级与日量分离，打卡不自动加量。目标人群为普通成年男性，研究多为术后/疾病男性，外推不能假定成立。

APP基础能力沿用 V2.0 已签收版本：LIGHT/DARK/SYSTEM默认SYSTEM；FOLLOW_SYSTEM默认、zh-CN/en、未支持语言回退zh-CN；响应系统变化，重启持久化，沉浸页主题一致，切换不丢训练/历史/额度；复用Compose Material3、Android strings/raw资源与DataStore，未来ru/ko/th只增资源与必要适配。新组数/剂量/安全文案一并中英化，不重构基础引擎。

## User Flow

- FLOW-01：沿用动作教育、五维自报、非诊断结果；摸底可选。继承签收版本：第2项正计时≤10秒可提前停；第3项按第2项秒数逐轮自动计时/计数、休息倒计时及5秒延长；第4项滑块1–10；语音/tick。结果仅建议，不锁等级。
- FLOW-02：首页一键训练，开始前显示当前选择/本次执行量、组数、时长、日已用/剩余；耐力多组→休息→快速多组→结束；暂停/恢复/提前结束沿用。L6/N=6 显示六个时段及预计全天跨度；不设置量权限门槛，真实症状停止。
- FLOW-03：沿用专项入口及分项留痕，仅所选类型；共用日额/时段，不能绕限。
- FLOW-04：沿用主动重测、取消不改当前选择与历史、确认更新建议；自由选L1–L6，短板结果仅为建议，不锁等级或量权限，不自动升级。
- FLOW-05：沿用暂停/焦点/安全退出；新增疲劳、尿流异常及漏尿加重反馈，停活跃收缩、记录理由、恢复/求助。
- FLOW-06：沿用无声字幕及锁屏暂停、6日恢复；新增连续3个高量日后的恢复提示与整日半量。
- FLOW-07：沿用EHS默认关闭、可选1–4/跳过/关闭/独立趋势/单独清除，与Level/剂量/进阶完全独立。

## FR-005｜频次与双维额度确定性换算（本版勘误）

提醒沿用默认2、可选1/2/3；会话另选N∈{1,2,3,4,6}、持久化，默认见矩阵。N是计划启动次数，不是组数或提醒次数。以下是完整组合日计划；专项只消费对应类型和计划时段，不创造或转移另一类型额度。

1. 本地日首次规划冻结Level/N/半量及doseVersion=3；无阶段A、许可C或新用户≤45门槛。矩阵每会话E、每日快速F；正常耐力日额E_D=E×N，快速日额F_D=min(F,240,N×(40−E))。少会话先按单会话剩余容量降快速，不放大耐力补齐；两类日合计**没有240总量限制**。
2. 半量：E_Q=floor(E_D/2)、F_Q=floor(F_D/2)；正常原值。时段i分别分配e_i=floor(E_Q/N)+[i≤E_Q mod N]，f_i=floor(F_Q/N)+[i≤F_Q mod N]。余数从第1时段起分配，各类求和精确；正常e_i=E，各次e_i+f_i≤40。零类型可专项，双零仅休息。半量L2/N3＝9耐力+10快速=19；L6/N6＝30+60=90，每次5+10。
3. 启动读当日实际已开始E_used/F_used（含摸底/专项/中止），e=min(e_i,max(0,E_Q−E_used))；f=min(f_i,max(0,F_Q−F_used),max(0,240−F_used))。某类不足1时不启双类组合，可执行有额类型专项；不足不互转。规划和每次收紧开始双层检查：单会话已开始合计<40、类型余量>0、快速当日已开始<240；越界下一收紧不发生。
4. 每时段最多一次启动；专项消费同一时段，仅执行本时段同类额。中止未做量不补到后续，重开无新时段；暂停恢复同session幂等且不重复扣已开始收紧。摸底按真实开始的保持/耐力收紧扣E；快速滑块是自报不虚扣F，不计完成会话、不消耗训练时段，额度不足提示次日。
